# Feature-by-feature QA through the screens: 5 November 2026

Every feature in the hub was used through the real screens, the way a member or the team would: open the screen, fill its
form, press its button, and check that the result appears (and, for saved work, that it is still there after a reload). A
step fails on a crash screen, a browser error or any server error, and a screenshot is saved.

Code tested: `main` at the login-fix merge (new design, AiSensy-only login codes).

**Result: 106 of 106 feature checks pass on a phone (390 px) and 106 of 106 on a computer (1366 px). No app defects found.**

## Set-up
- Real MongoDB 8.0 and the app started the way production starts it: 2 workers.
- Outside services in test mode (`QA_MODE`). AI, web search, audio and video analysis return sample answers. Payments use
  the test-mode Razorpay flow, and login codes are shown on screen.
- Pitch Practice was tested with a real 20-second MP4 file.
- Script: `scripts/qa/ui_features.js`. Run it against any QA-mode copy:
  ```bash
  HUB_URL=https://staging.example.com PITCH_VIDEO=./pitch.mp4 node scripts/qa/ui_features.js ./shots phone
  ```
  Use `desktop` instead of `phone` for the 1366 px run.

## Also run on the same code
- `pytest`: 363 passed. `ruff`: clean. Frontend production build: clean.
- API end-to-end on the same server (`scripts/qa/e2e_api.py`): 236 of 236 passed, 0 server errors.
- Server log after all runs: no errors and no tracebacks.
- Database after the runs: records saved for every tool, including readiness scores, snapshots, case answers, briefs,
  decks, visuals, documents, websites and visitor messages, audio, reports, tickets, chats, offer cards, stories, insight
  packs, portfolio projects, pitch takes, notebooks, contacts, outreach, radar runs, call preps, proposals, diagnostics
  and their answers, social posts, bootcamp submissions, recaps, knowledge-base documents, subscriptions and inbox
  messages.

## What was tested
- Real flows that cross between people:
  - The member writes to support; the team replies; the member sees the reply in their inbox.
  - The team starts L2 for a ₹1,999 member, who can then open L2 tools.
  - The team uploads Akshat's material, and Akshat AI answers from it.
  - The team adds a bootcamp; an L2 member submits the task; the team reviews it; the member sees the feedback.
  - A visitor writes from a member's public website, and the message shows in the member's Website Builder.
  - A prospect fills a member's Client Diagnostic without logging in, and the response shows for the member.
- Plan rules: the free account gets each webinar tool once, and a second go is refused both on screen and by the server.
  Paid tools show the lock card on lower plans. After the test payment, the ₹1,999 tools open.
